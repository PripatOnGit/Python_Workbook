# Loops

This folder focuses on loop logic: repeating work, counting, summing, searching, and pattern recognition.

## What to practice

- Understand when a loop is needed
- Identify the loop variable and what it tracks
- Distinguish between counting, accumulating, and searching loops
- Write the logic before coding

## Core ideas

- `for` loops are best when the number of iterations is known or you are iterating over a collection
- `while` loops are useful when the condition drives the stopping point
- A loop usually does one of these jobs:
  - count occurrences
  - accumulate a total
  - search for a match
  - print or build a pattern

## Practice problems

1. Print numbers from 1 to 10
2. Print even numbers from 1 to 20
3. Find the sum of numbers from 1 to 10
4. Count how many times a given character appears in a string
5. Find the sum of all elements in a list
6. Find the largest number in a list
7. Print the multiplication table for a given number
8. Print the following pattern:
   ```
   *
   **
   ***
   ****
   *****
   ```
9. Check if a number is prime
10. Reverse a string using a loop

## Interview method

For each problem:
1. Write the input and output clearly
2. Identify what the loop is tracking
3. Decide whether to count, add, search, or build
4. Write pseudocode first
5. Then code in Python

## Good questions to ask yourself

- What is changing every iteration?
- What should stop the loop?
- Am I counting, adding, or checking a condition?
- Can this be done with a simpler pattern?

## Suggested next step

Move to the next logic topic only after you can explain the loop behavior out loud without reading the code.
