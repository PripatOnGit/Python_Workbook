# Functions

Functions help you break a larger problem into smaller pieces.

## Core idea

A function is a named block of code that performs a specific task.

Use functions when:
- the same logic repeats
- a problem can be broken into substeps
- you want cleaner, reusable code

## Important ideas

- function name should explain the task
- parameters pass input into the function
- return values send output back
- one function should ideally do one job

## Practice problems

1. Write a function to add two numbers
2. Write a function to check if a number is even
3. Write a function to find the largest of two numbers
4. Write a function to calculate the factorial of a number
5. Write a function to reverse a string
6. Write a function to count vowels in a string
7. Write a function that returns the area of a rectangle
8. Write a function that checks if a number is prime
9. Write a function that prints a multiplication table
10. Write a function that returns the sum of all numbers in a list

## Interview approach

1. Identify the job the function should do
2. List the input(s)
3. Decide what output the function should return
4. Write pseudocode
5. Then implement the function

## Example

```python
def add_numbers(a, b):
    return a + b

result = add_numbers(3, 5)
print(result)
```

## Questions to ask

- What should the function accept?
- What should it return?
- Is the function doing only one thing?
- Can I reuse this logic elsewhere?
