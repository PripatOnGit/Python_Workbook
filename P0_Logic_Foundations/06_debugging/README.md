# Debugging

Debugging is the skill of understanding why a program is not doing what you expect.

## Core idea

Code often fails because of one small issue, such as:
- wrong condition
- wrong loop range
- incorrect variable value
- using the wrong operator
- missing return statement

## Helpful debugging habits

1. Read the error message carefully
2. Print the variable values at key points
3. Check the flow of logic step by step
4. Use small test inputs
5. Explain the code to yourself or another person
6. Fix one issue at a time

## Practice problems

1. Understand why a loop is running too many times
2. Fix a wrong condition in an if statement
3. Trace a program with a wrong total value
4. Find the bug in a function that returns the wrong result
5. Debug an input validation issue
6. Spot an off-by-one error in a range
7. Detect why a variable always stays at zero
8. Find a missing return statement bug

## Example debugging mindset

Instead of guessing, ask:
- What value is the variable holding right now?
- At which step does it change unexpectedly?
- Is the condition evaluating the way I expect?
- Did the loop stop at the right point?

## Good debugging questions

- What was the expected behavior?
- What is the actual behavior?
- Where did the logic diverge?
- Which variable or condition is causing the difference?

## Rule to remember

Do not patch code blindly. Trace the logic, test the hypothesis, and confirm the fix.
