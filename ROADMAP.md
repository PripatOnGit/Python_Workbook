# Python Prep Roadmap

This repository is organized by the learning phases from the prep plan.

## Phase order

- P0_Logic_Foundations: build problem decomposition and programming logic
- P1_Python_Fundamentals: syntax, collections, file handling, OOP, and Python basics
- P2_Problem_Solving_Patterns: arrays, strings, hashing, recursion, stacks, queues, and complexity
- P3_Data_Manipulation: NumPy, pandas, SQL, and regex
- P4_Data_Engineering_Core: ETL, databases, APIs, Airflow, cloud, Docker, and Spark
- P5_GenAI_Agent_Building: LLMs, RAG, agents, frameworks, and deployment

## Recommended flow

1. Complete the current phase before moving to the next.
2. Add notes and practice files inside each subfolder.
3. Keep examples small and explainable.
4. Revisit old folders after each phase to reinforce weak points.
