# Arrays and Strings

This section focuses on common interview patterns involving ordered data and text.

## Core ideas

- Arrays store ordered values in a list-like structure
- Strings are sequences of characters
- Problems often require counting, scanning, comparing, or transforming data
- Many solutions start with a brute-force approach, then improve with pattern-based logic

## Practice problems

1. Find the largest number in an array
2. Find the sum of all numbers in an array
3. Check if a string is a palindrome
4. Count vowels in a string
5. Remove duplicate characters from a string
6. Find the most frequent element in an array
7. Check if two strings are anagrams
8. Find the longest substring without repeating characters
9. Find the first repeated element in a list
10. Reverse each word in a sentence

## Thinking patterns

- Count frequencies
- Scan from left to right
- Compare characters or elements
- Use two pointers when order matters
- Use a dictionary when you need lookup by value

## Interview tip

Before writing optimized code, first explain the brute-force idea clearly.
