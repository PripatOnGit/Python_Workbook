# Two Pointers

Two pointers is a pattern where you move two indices through a data structure to solve a problem efficiently.

## Core idea

The two pointers usually move in the same direction, toward each other, or at different rates depending on the problem.

## Common patterns

- left and right pointer for array problems
- fast and slow pointer for cycle detection or middle finding
- sliding window variant for contiguous subarrays

## Practice problems

1. Check if a string is a palindrome
2. Find two numbers that sum to a target
3. Remove duplicate values from a sorted array
4. Reverse an array in-place
5. Merge two sorted arrays
6. Find the pair with the smallest difference
7. Check if an array is sorted
8. Move zeros to the end of a list

## Interview tip

Two pointers is useful when you need to optimize from O(n^2) to O(n) by avoiding repeated nested scans.
