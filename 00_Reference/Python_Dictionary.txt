1. Essential Concepts & MethodsCore Syntax & Accessdict[key]: Directly accesses a value. Raises a KeyError if the key doesn't exist.dict.get(key, default=None): Safely retrieves a value without raising an exception. If key is missing, returns default.dict.setdefault(key, default): Returns the value if key exists; if not, inserts key with default as its value and returns default.Iterationdict.keys(): Returns a view object of all keys.dict.values(): Returns a view object of all values.dict.items(): Returns a view object yielding (key, value) tuples.Manipulation & Mergingdict.pop(key, default): Removes key and returns its value. Raises KeyError if missing and no default is provided.dict.popitem(): Removes and returns the last inserted (key, value) pair (LIFO order).dict.update(other_dict): Updates the dictionary in-place with key-value pairs from another dictionary/iterable.dict1 | dict2 (Python 3.9+): Merges two dictionaries into a new dictionary (right-hand side overwrites duplicate keys).{**dict1, **dict2}: Merges dictionaries using keyword unpacking.2. Advanced & Special Dictionary Typescollections.defaultdictAutomatically initializes missing keys with a default value based on a factory function (e.g., list, int, set).Interview Use Case: Counting items or grouping elements without needing if key not in dict checks.Pythonfrom collections import defaultdict

3. How Python Handles Dictionaries InternallyInterviewers frequently ask about dictionary internals to test your depth in Python and computer science fundamentals.1. Hash Tables Under the HoodPython dictionaries are implemented as hash tables.To look up a key, Python computes hash(key). The hash value determines the index in an internal array where the pointer to the key-value pair is stored.2. Key Requirements: Hashability & ImmutabilityCondition: A key must be hashable.Hashable objects must have a hash value that never changes during their lifespan (__hash__()) and must be comparable to other objects (__eq__()).Allowed as keys: Strings, integers, floats, tuples (containing only hashable elements), frozensets.Not allowed as keys: Lists, dicts, sets (unhashable/mutable).3. Time ComplexitiesOperationAverage CaseWorst CaseLookup (dict[key])$\mathcal{O}(1)$$\mathcal{O}(n)$Insertion (dict[key] = val)$\mathcal{O}(1)$$\mathcal{O}(n)$Deletion (del dict[key])$\mathcal{O}(1)$$\mathcal{O}(n)$Why Worst Case $\mathcal{O}(n)$? High numbers of hash collisions or frequent table resizing/rehashing can temporarily degrade performance to $\mathcal{O}(n)$, though Python's hashing algorithm and resizing logic make this extremely rare in practice.4. Memory Optimization & Order Preservation (Python 3.6+)Since Python 3.6 (made an official language spec in 3.7), dicts use a compact array representation:Indices Array: A sparse array containing indices pointing into the entries array.Entries Array: A dense array storing [hash_code, key_ptr, value_ptr] in the exact order they were inserted.Benefits:Reduces memory usage by ~20% to 25% compared to pre-3.6 dictionaries.Makes dictionary iteration inherently insertion-ordered.
