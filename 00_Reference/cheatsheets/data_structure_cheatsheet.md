# Data Structure Quick Guide

## List

- Ordered
- Mutable
- Supports indexing and slicing
- Good for ordered collections

Use when:
- preserving order matters
- you need repeated access by index

## Dictionary

- Key-value pairs
- Fast lookup by key
- Great for frequency maps and caching

Use when:
- counting values
- looking up by key
- grouping related values

## Set

- Unique values only
- Fast membership checking
- Good for deduplication

Use when:
- checking if something exists
- removing duplicates
- comparing two collections

## Stack

- LIFO: last in, first out
- Use for nested structures and reverse order

Typical problems:
- valid parentheses
- expression evaluation
- backtracking

## Queue

- FIFO: first in, first out
- Use for ordering tasks or processing in sequence

Typical problems:
- job scheduling
- breadth-first traversal
- message processing

## String

- Sequence of characters
- Common operations: slicing, split, join, replace

Typical problems:
- palindrome
- anagram
- substring checks
