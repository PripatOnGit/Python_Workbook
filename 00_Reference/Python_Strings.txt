Immutability & Re-allocationIn Python, strings are immutable objects (specifically PyUnicodeObject in CPython).Once allocated in memory, the contents of a string cannot be modified.Any operation that appears to mutate a string (like .replace(), .upper(), or + concatenation) actually allocates a brand-new memory block for the new string and leaves the original untouched.Pythons = "cat"

2. String Interning (Memory Optimization)To save memory and speed up dictionary/lookup operations, Python uses String Interning.What it is: Python reuses existing string instances in memory instead of creating duplicates.Automatic Interning: CPython automatically interns string literals that look like Python identifiers (alphanumeric characters + underscores) and short strings.Why it matters: Comparing interned strings using is is instantaneous ($O(1)$) because Python only compares memory pointers rather than checking character-by-character ($O(N)$).Pythona = "hello_world"
b = "hello_world"

print(a is b)  # True! Both variables point to the SAME memory address.

6. Primary Algorithmic Patterns for String QuestionsPattern 1: Two PointersCommon Applications: Valid Palindrome, Reverse Vowels, String Compression.Key Concept: Pointer left starts at 0, pointer right starts at len(s) - 1. Move towards middle.Pythondef is_palindrome(s: str) -> bool:
    left, right = 0, len(s) - 1
    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1
        if s[left].lower() != s[right].lower():
            return False
        left += 1
        right -= 1
    return True
Pattern 2: Sliding WindowCommon Applications: Longest Substring Without Repeating Characters, Minimum Window Substring, Find All Anagrams.Key Concept: Maintain a dynamic subarray/substring defined by left and right indices while updating a hash map or set of character frequencies.Pythondef length_of_longest_substring(s: str) -> int:
    seen = {}
    left = 0
    max_len = 0
    for right, char in enumerate(s):
        if char in seen and seen[char] >= left:
            left = seen[char] + 1
        seen[char] = right
        max_len = max(max_len, right - left + 1)
    return max_len
