# Reference and Quick Prep Guide

This folder is meant for fast revision, not for new learning. Keep only the snippets, patterns, and reminders that you want to review quickly before practice or interviews.

## Contents

- cheatsheets: Python, data structures, regex, SQL, and complexity notes
- common_patterns: interview pattern templates and repeatable problem-solving approaches
- notes: mistakes, reminders, and personal revision points

## How to use this folder

- Review this before a practice session
- Use it to refresh your memory on common patterns
- Keep summaries short and actionable
- Add only the concepts you keep forgetting
