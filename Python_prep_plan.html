Learning Roadmap · Python → Data Engineer → GenAI

Build a brain that can break down any problem into steps.

Starting: Know basics, shaky on logic
Time: 1–2 hrs / day
Target: Data Engineer → GenAI / Agent Building
Goal isn't just "finish topics" — it's building a brain that can break down ANY new problem into steps. We do this through daily deliberate practice, not passive video-watching.
P0
Logic Building Foundations
Weeks 1–3
▶ Active
Before more Python syntax, you need the thinking muscle. Most people who "know Python" but freeze on problems skipped this.
  • Week 1: Flowcharts & pseudocode — translating a problem into steps before writing code
  • Week 1: Variables, data types, input/output — framed as "state tracking"
  • Week 2: Conditionals — decision trees, truth tables, nested logic
  • Week 2: Loops — for/while, loop patterns (counting, accumulating, searching)
  • Week 3: Functions — decomposition, single responsibility, parameters vs return
  • Week 3: Debugging mindset — reading tracebacks, print-debugging, rubber-duck method
Daily rhythm: 1 concept (20 min) + 3–5 small problems (40–60 min), no exceptions.
P1
Python Fundamentals — Solidify
Weeks 4–6
  • Strings, lists, tuples, dicts, sets — deep dive with manipulation problems
  • List/dict comprehensions (huge for data work)
  • Exception handling (try/except) — real-world robustness
  • File I/O (txt, csv, json)
  • Modules, packages, virtual environments
  • OOP basics (classes, objects) — enough to read others' code and structure yours
P2
Problem-Solving Patterns / Light DSA
Weeks 7–10
Not full competitive-programming DSA — the patterns that appear everywhere in interviews and real logic.
  • Two pointers, sliding window
  • Recursion (and how to think recursively)
  • Sorting & searching (concept + when to use)
  • Basic time/space complexity (Big-O) — just enough to reason about "will this scale"
  • Arrays/strings problem sets (pattern-matching, frequency counting)
  • Dictionaries/hashmaps for optimization
  • Stack/Queue basics
Practice: Solve on paper first → LeetCode Easy/Medium or HackerRank, 3–5 problems/week, always with pseudocode first.
P3
↕ P2
Data Manipulation Toolkit
Weeks 8–12
  • NumPy — arrays, vectorized thinking (why loops are often wrong in data work)
  • Pandas — the real workhorse: filtering, grouping, merging, reshaping, cleaning
  • SQL — parallel track, non-negotiable for Data Engineer (joins, window functions, CTEs, query optimization)
  • Regex — pattern matching for messy data
P4
Data Engineering Core
Weeks 13–20
  • Databases deep dive: relational design, indexing, normalization
  • ETL/ELT concepts and building pipelines in Python
  • Working with APIs (requests, pagination, auth)
  • Orchestration: Airflow (or Prefect) basics
  • Big data intro: Spark/PySpark fundamentals
  • Cloud basics: one of AWS/GCP/Azure (storage, compute, basic data services)
  • Data formats: JSON, Parquet, Avro — why they matter
  • Version control: Git/GitHub (start Week 1 alongside logic building!)
  • Docker basics (containerizing a pipeline)
P5
↕ P4
GenAI & Agent Building
Weeks 18–26
  • LLM fundamentals: tokens, embeddings, context windows, prompting
  • Using LLM APIs (OpenAI/Anthropic SDKs) — the plain Python way first
  • Prompt engineering fundamentals
  • RAG (Retrieval Augmented Generation): vector databases (Chroma/Pinecone/FAISS), embeddings, chunking strategies
  • Frameworks: LangChain / LlamaIndex basics
  • Agent concepts: tools, function calling, ReAct pattern, multi-step reasoning
  • Building your own simple agent from scratch (no framework) — to truly understand internals
  • Then: agent frameworks (LangGraph, CrewAI, or similar)
  • Deploying a GenAI app (simple API + maybe Streamlit/Gradio UI)
