Default Parameters (The Mutable Default Trap)Crucial Interview Trap: Never use a mutable object (like a list or dict) as a default parameter value because defaults are evaluated once when the function is defined, not every time it is called.❌ Bad (Causes state bug across calls):Pythondef append_to(element, target=[]):
    target.append(element)
    return target
✅ Good (Pythonic fix):Pythondef append_to(element, target=None):
    if target is None:
        target = []
    target.append(element)
    return target

3. Advanced Function ConceptsA. Lambda (Anonymous) FunctionsShort, single-expression functions. They cannot contain multiple statements or explicit return keywords.Python# lambda arguments: expression
square = lambda x: x ** 2
B. Higher-Order Functions (map, filter, reduce)Functions that take other functions as parameters.Pythonnums = [1, 2, 3, 4, 5]

# map: Transforms each element (returns an iterator)
squared = list(map(lambda x: x ** 2, nums)) # [1, 4, 9, 16, 25]

# filter: Keeps elements where function returns True (returns an iterator)
evens = list(filter(lambda x: x % 2 == 0, nums)) # [2, 4]

# reduce: Aggregates list to a single value
from functools import reduce
total_sum = reduce(lambda acc, x: acc + x, nums) # 15
C. Closures & Inner FunctionsA closure occurs when an inner function remembers and has access to variables in its enclosing scope, even after the outer function has finished executing.Pythondef make_multiplier(factor):
    def multiply(number):
        return number * factor  # 'factor' is remembered from enclosing scope
    return multiply

double = make_multiplier(2)
print(double(5)) # Output: 10
D. DecoratorsDecorators wrap a function to extend or modify its behavior without permanently altering the code inside it.Pythonimport functools

def my_logger(func):
    @functools.wraps(func) # Preserves original function's name and docstring
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}...")
        result = func(*args, **kwargs)
        print("Done!")
        return result
    return wrapper

@my_logger
def add(a, b):
    return a + b
