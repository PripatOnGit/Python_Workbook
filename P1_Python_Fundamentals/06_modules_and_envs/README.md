# Modules and Environments

This section introduces Python modules and the idea of isolated project environments.

## Core concepts

- Python modules are reusable `.py` files
- Packages are groups of modules
- `import` loads code from another file or library
- Virtual environments isolate project dependencies

## Practice ideas

1. Import a custom module from another file
2. Use `math` for calculations
3. Use `random` to generate a random number
4. Use `datetime` to print today's date
5. Create a small helper module and import it
6. Run a script in a virtual environment
7. Compare project dependencies between environments
8. Explain why environments matter in real projects

## Example

```python
import math

print(math.sqrt(16))
```

## Why this matters

Different projects may need different libraries or versions. Virtual environments prevent conflicts and keep your work reproducible.
