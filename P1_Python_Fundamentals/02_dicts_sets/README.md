# Dictionaries and Sets

These are powerful Python data structures for counting, grouping, and searching efficiently.

## Core ideas

- A dictionary stores key-value pairs
- A set stores unique values only
- Dictionaries are useful for frequency maps and lookups
- Sets are useful for membership checks and deduplication

## Practice problems

1. Count character frequency in a string
2. Store a student record in a dictionary
3. Find keys present in two dictionaries
4. Remove duplicates from a list using a set
5. Check membership in a set
6. Create a frequency table for a list of numbers
7. Group words by first letter
8. Find common elements between two lists using sets
9. Build a dictionary from two parallel lists
10. Check if a set is empty

## Useful methods

- `dict.keys()`
- `dict.values()`
- `dict.items()`
- `get()`
- `set()`
- `add()`
- `remove()`
- `update()`

## Interview tip

Use dicts when you need fast lookup by key and sets when you need uniqueness or membership checks.
