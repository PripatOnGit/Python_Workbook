# Strings and Lists

This topic covers the most common Python data types used in interviews and real projects.

## Key concepts

- Strings are sequences of characters
- Lists are ordered, mutable collections
- Indexing starts from 0
- Slicing helps extract parts of a sequence
- Common operations: append, pop, sort, reverse, join, split

## Practice problems

1. Reverse a string
2. Check whether a string is a palindrome
3. Count vowels in a string
4. Remove spaces from a sentence
5. Find the most frequent character in a string
6. Reverse a list
7. Find the second largest number in a list
8. Remove duplicates from a list
9. Sort a list without using built-in sorted
10. Merge two lists and remove duplicates

## Useful Python methods

- `len()`
- `split()`
- `join()`
- `strip()`
- `replace()`
- `append()`
- `pop()`
- `sort()`
- `reverse()`
