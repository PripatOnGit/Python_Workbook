# Python Interview Practice Workbook

This project is organized by topic so it is easier to revise core concepts and build toward more advanced interview logic.

## Structure

- 00_Reference: quick syntax and concept notes
- 01_Python_Fundamentals: basic Python, control flow, functions, and practice scripts
- 02_Data_Structures: list, set, queue, and stack exercises
- 03_Problem_Solving: arrays, strings, hashing, two-pointer, and recursion drills
- 04_Object_Oriented_Programming: class and inheritance examples
- 05_File_IO: CSV/JSON file handling and related tasks
- 06_Advanced_Topics: exception handling and more advanced Python topics

## Recommended revision flow

1. Start with the basics in 01_Python_Fundamentals.
2. Move to the data structures in 02_Data_Structures.
3. Solve the pattern-based problems in 03_Problem_Solving.
4. Revisit object-oriented and file-handling topics.
5. Practice explaining the logic aloud before interviews.

## Interview tips

- Read the problem statement and identify the input/output pattern.
- Write down brute-force logic first, then optimize.
- Practice time and space complexity for every solution.
- Keep the code readable and explainable in plain English.
